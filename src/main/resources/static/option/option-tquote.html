说明

合约K线取自 base_option.kline_his；内在价值 / 时间价值 / 杠杆 基于标的ETF 当日收盘价计算； 若该合约当日无成交，涨跌按「上一根K线收盘」计算。

期权 T型报价 · 字段说明

左侧为认购（Call），右侧为认沽（Put），中间为行权价；同一行权价 认购/认沽 对齐显示。 页面已把「筛选月份」替换为「筛选日期」，月份以 Tab 形式自动分组。

数据与接口

统一入口：static/js/config.js → window.ApiUtils （ENV — · —）

  • GET /api/option/listOptionInDate?date=&underlyingCode= — 指定日期的 合约分组（合约月份 - 认购/认沽列表，含月度统计与派生指标）
  • GET /api/option/underlyingList?date= — 指定日期 存续合约的 标的列表 + 标的ETF行情
  • GET /api/option/underlyingKline?underlyingCode=&date=&months=3 — 标的ETF K线（前后 N 个月）
  • GET /api/option/kline?code= — 单合约 K线（详情抽屉）
  • GET /api/option/tradeDates?underlyingCode= — 交易日历（上一/下一交易日、日期校验）

行情口径

  • 最新价：所选日期当日（或之前最近一根）kline_his 的收盘价；若当日无成交，显示最近行情日并置灰（合约代码旁有黄点）。
  • 涨跌 / 涨跌幅：以「上一根K线收盘」为昨收重算，保证 历史合约（Excel导入）与 存续合约（通达信导入）口径一致。
  • 成交额：通达信导出的存续合约 kline 不含成交额，此时显示 —（历史合约有真实成交额）。
  • 内在价值：认购 max(0, S-K)，认沽 max(0, K-S)；时间价值 = 最新价 - 内在价值；S 为标的ETF 收盘价。
  • 杠杆 = 标的价 / 权利金；盈亏平衡 = 认购 K+权利金，认沽 K-权利金。
  • 实/平/虚：按行权价与标的价格比较；平值 = 最接近标的价的行权价。

快捷键

  • ← / → 上一 / 下一交易日；1..9 切换合约月份；r 刷新；Esc 关闭抽屉/弹窗。
