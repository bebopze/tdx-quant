一键清仓（全部持仓）

最高风险 GET /quick/clearPosition
后端流程：① 先撤销全部未成交委托（含买单）→ ② 等待并重新读取持仓 → ③ 逐笔提交卖出平仓委托 （固定 SELL_CLOSE + 限价，价格 = 当前价 × 0.995）。不代表保证清仓或立即成交。

需输入确认词 CLEAR。

P0-01 后端阻断：服务层 check___totalAccount__equalRatioSellPosition() 先断言 “实际总仓位 < 目标仓位”，随后又要求 “实际总仓位 − 目标仓位 > 0.05”，正常数值无法同时成立， 该接口按当前代码不能作为可用减仓功能。前端保留 UI 与接口映射，但不发出真实请求。 后端修复并完成边界/方向测试后，将本文件 CONFIG.BLOCKERS.totalAccountEqRatio 置为 false 方可解除。

当前持仓等比减仓 风险确认后可用

以当前持仓市值为 100% 基准；例如保留 50% ⇒ 理论上卖出 50%。
P0-02 / P0-04 风险（后端未修复）：
  • equalRatio_sellPosition() 使用 StockUtil.quantity(qty, avail) 股票 100 股取整规则，小于 100 张的期权持仓可能被取整为 0 或 100，比例偏差明显。
  • 等比减仓固定使用 SELL_CLOSE，未按持仓 Ccfx 区分权利仓/义务仓；对义务仓可能方向错误。
  • 接口返回 Void，单笔失败可能被服务层吞掉，必须刷新持仓与委托核对。
